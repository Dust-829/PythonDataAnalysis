# AGENTS.md

## 项目目标

按照《Python 数据分析》课程指导书完成期末大作业。项目主题为“电影评分与受欢迎度分析”。项目必须包含数据采集、数据清洗、统计分析、数据可视化、数据挖掘模型、Streamlit 展示页面和最终实验报告。

## 必需交付物

- 可运行的项目源代码和脚本。
- 原始数据、中间数据和最终处理数据。
- 数据说明文档，说明字段含义、数据单位、采集时间和数据范围。
- 报告中使用的图表、统计表和模型指标。
- Streamlit 数据分析展示页面。
- DOCX 格式的最终实验报告。
- 按课程要求命名的最终工程压缩包。

## 数据集计划

使用公开电影数据集：

- MovieLens 最新数据集作为主要评分和标签数据来源。
- IMDb 非商业数据集作为电影元数据和外部评分数据来源。
- 使用 MovieLens `links.csv` 和 IMDb `tconst` 合并两个数据源。

最低要求：

- 至少 2 个数据采集脚本。
- 最终处理数据不少于 20,000 条记录。
- 合并和特征工程后不少于 20 个有效字段。
- 在 `data/data_dictionary.md` 中记录来源 URL、采集时间、行数、文件说明、字段含义和数据范围。

## 实现规则

- 使用 Python 3.x。
- 优先使用 `pandas`、`numpy`、`scikit-learn`、`matplotlib`、`seaborn`、`streamlit` 和 `requests`；展示页优先使用 Streamlit 自带图表，减少额外依赖。
- 所有脚本都应能从 `final_project` 目录运行。
- 将 `README.md` 作为滚动项目计划和面向用户的项目说明。实际数据源、目录结构、脚本名称、模型选择、输出文件或报告状态发生变化时，必须同步更新 `README.md`。
- 原始下载文件存放在 `data/raw/`，清洗过程中不要覆盖原始数据。
- `src/generate_demo_data.py` 只能用于无网络环境下的本地流程烟测，不得作为最终课程提交数据来源。
- 清洗后的中间数据存放在 `data/interim/`。
- 最终建模数据存放在 `data/processed/`。
- 生成的图表存放在 `output/figures/`。
- 生成的统计表存放在 `output/tables/`。
- 生成的模型指标存放在 `output/metrics/`。

## 分析要求

项目必须覆盖课程指导书中的全部主要给分点：

- 数据采集：实现至少 2 个采集脚本，以 CSV、Excel、JSON 或数据库文件形式持久化保存数据，并编写数据说明文档。
- 缺失值处理：检测缺失值，可视化缺失分布，选择合理处理方案，并说明选择原因。
- 重复值处理：识别完全重复和业务逻辑重复记录，删除无效重复数据，并报告去重前后数据量。
- 异常值和错误值处理：使用箱线图、Z-score 或业务规则检测异常值；处理格式错误和逻辑错误。
- 数据标准化：统一日期、数值、字符串格式和数据类型。
- 数据合并与特征处理：合并多个数据集，处理主键冲突和冗余字段，并对分类变量进行编码。
- 描述性统计：计算均值、中位数、方差、标准差、分位数、频数和频率。
- 数据可视化：生成折线图、柱状图、饼图、散点图、缺失值热力图、相关性热力图、箱线图、直方图、时序图和词云。
- 分组、透视与交叉分析：生成分组聚合、数据透视表和交叉统计结果。
- 相关性分析：计算 Pearson 或 Spearman 相关系数，并解释正相关、负相关、线性或非线性关系。
- 时间序列分析：基于评分时间或上映年份分析趋势，包括移动平均或同比/环比分析。
- 业务洞察与归因分析：解释异常数据、核心指标波动和有实践价值的结论。
- 分布分析：使用直方图、QQ 图、偏度和峰度分析核心数值字段分布。
- 回归模型挖掘：实现至少 2 个回归模型，并使用 MAE、MSE 和 R2 评价。
- 分类模型挖掘：实现至少 4 个分类模型，并使用准确率、精确率、召回率、F1、ROC 曲线、AUC 和混淆矩阵评价。
- 聚类模型挖掘：实现至少 2 个聚类模型，可视化聚类结果，并解释每一类的含义。
- 创新点：构建 Streamlit 数据分析展示页面，增加词云或异常检测等额外分析，并总结有实践指导价值的结论。

- 所有脚本运行时没有路径错误。
- 主要输出可以复现。
- 最终处理数据满足 20,000+ 记录和 20+ 字段要求。
- 报告说明了每个清洗和建模选择的原因。
- 展示页面可以通过 `streamlit run app/streamlit_app.py` 运行。
- 最终压缩包不包含 `__pycache__`、`tmp`、渲染中间文件和 demo 数据；优先使用 `src/make_submission_zip.py` 生成提交压缩包。
